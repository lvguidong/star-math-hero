# 🚀 星际数学小勇士

面向小学二年级的「100 以内加减法」**飞行射击闯关游戏**。口号：**算出答案，给飞船充能！**

完整策划见 [游戏策划案](./星际数学小勇士_游戏策划案.md)，工程方案见 [开发计划书](./星际数学小勇士_开发计划书.md)。

## ✨ 游戏特色

- **真正的飞行战斗**：飞船在画面里真实飞行，陨石与敌机迎面而来；**答对题 = 发射激光击碎目标 + 冲刺加速**，答错会掉护盾；孩子用鼠标点击 ◀ ▶ 按钮（或键盘 ← →）左右闪避；每关最后一题是 **Boss 战**，答对击败 Boss。
- **6 大星系、56 关**：启航星港 → 流星群 → 银河工厂 → 双星系统 → 应用星云 → 数学黑洞 Boss，题型覆盖整十数、不进位/进位加法、不退位/退位减法、连加连减、比多少、应用题 8 类。
- **只为「好玩」设计**：连击彗星、三星评价、阶梯难度、星星图鉴、6 只外星宠物、成就勋章、**《歌唱祖国》轻柔八音盒背景音乐**（按简谱用 Web Audio 程序化合成，纯正弦音色+高八度泛音+缓入缓出，全程循环播放、首次点击后出声，可在设置里关闭；无需音频文件，离线可听）、激光/爆炸/受击/Boss 战斗音效与中文语音夸奖、Canvas 飞行粒子特效。
- **节奏顺畅**：答对后自动进入下一题（或自动结算），无需再点「下一题」；答错才需手动「继续」思考。
- **防挫败**：三级提示（小棒 → 数轴 → 凑十法）、答错不扣分、连错 3 题自动降难度、护盾耗尽自动补满（不会 Game Over）、错题本答对 2 次治愈。
- **家长面板**：学习报告（各题型掌握度）、音效/语音/字号开关、**四选一 / 填数字作答切换开关**、每日时长限制、存档导出/导入/清空。
- **作答方式可选**：默认四选一；在家长面板开启「填数字作答」后改为手动输入数字发射激光，输入非法值会温和提示，设置随存档持久化。
- **离线可玩（PWA）**：首次加载后断网也能完整闯关；无外部网络请求、无隐私数据收集。

## 🚀 运行

要求 Node.js 18+（已在 Node 24 验证）。

```bash
# 若全局 npm 缓存无写权限（本环境如此），先设置本地缓存：
export npm_config_cache="$PWD/.npm-cache"

pnpm install          # 或 npm install
pnpm run dev          # 开发服务器，默认 http://localhost:5173
pnpm run build        # 类型检查 + 生产构建到 dist/
pnpm run preview      # 预览生产构建
```

浏览器打开首页 → 点击第一关「1-1」→ 飞船起飞，用鼠标点击 ◀ ▶ 闪避，点击选项（或键盘 `1`–`4`）作答发射激光，`H` 提示，`Enter` 下一题。若开启「填数字作答」，则改为在输入框填数字后点「🚀 发射！」或按回车。

## ✅ 验证（全部已通过）

```bash
pnpm run typecheck            # TypeScript 严格类型检查
pnpm run test                 # 130 个单元测试（含 4 万道题不变量断言、9 个飞行领域测试）
pnpm exec playwright test     # 8 个 E2E：飞行战斗（画布/闪避/激光/Boss）、星图、完整闯关、填数字作答、家长面板、PWA 资源、真断网可玩
```

E2E 使用系统 Chrome（`/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`），路径在 `playwright.config.ts` 中配置；其他平台改成对应的 Chrome/Chromium 路径即可。

## 📁 项目结构

```
src/
  domain/        纯领域逻辑：题目生成、干扰项、提示、计分、难度、错题本、关卡目录、收集系统、飞行规则(flight.ts)
  game/          Canvas 飞行引擎：FlightEngine（飞船/敌人/激光/粒子/震屏/Boss）
  application/   应用服务：状态机、存档、奖励、声音、应用控制器
  components/    React UI：星图、飞行竞技场(FlightArena)、答题卡、结算、收藏架、粒子特效、家长面板
  hooks/         状态订阅桥接
e2e/             Playwright 端到端测试（含 flight.spec.ts 飞行战斗验证）
public/          PWA manifest、Service Worker、图标
```

## 📌 说明

- 教育对齐人教版二年级上册「100 以内的加法和减法」。
- 存档保存在浏览器 localStorage（键 `sms_save_v1`），可通过家长面板导出/导入存档码迁移设备。
- 飞行逻辑为纯函数（`src/domain/flight.ts`，可单测），Canvas 引擎只负责绘制；激光命中采用扫掠检测，大帧间隔也绝不穿透。
- 语音朗读使用浏览器内置 SpeechSynthesis，优先挑选中文语音；无语音或关闭时静默降级，不影响游戏。
